# AI and Your Teaching

A workbook for new veterinary technology faculty, made for Week 7 (AI and Teaching) of the AVTE Vet Tech New Faculty Academy.

**Open the workbook:** https://octc-id.github.io/avte-ai-workbook/

## How it's built

Plain HTML, CSS, and JavaScript with no build step, so the same files run on GitHub Pages, another web host, or inside an LMS package.

- `index.html`: cover, how the workbook works, contents
- `chapters/`: one page per chapter
- `resources/`: supporting pages, like the ready-made case assignment
- `css/book.css`: the look (AVTE Amaranth for large accents, deep blue for text)
- `js/book.js`: autosave in the browser, print copies of answers, prompt builders, copy buttons

Answers save in the reader's browser (`localStorage`). Nothing is sent anywhere.
